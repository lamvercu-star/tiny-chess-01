A tiny chess engine in 4 KB of Python: negamax with alpha-beta, PVS, quiescence search, a transposition table, null-move pruning and piece-square tables, playing the make.fun tiny-chess-01 gauntlet. One file, standard library only, deterministic — a fixed 100,000-node budget per move.

## Run it

```sh
python3 main.py
```
